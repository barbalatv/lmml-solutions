## 1. Принцип: максимум ожидаемых очков в час

Перед стартом любой задачи — 5-минутный триаж:

1. **Что сдаётся?** Флаг/слово (CTF) или метрика (лидерборд). Если флаг, ищем, *где он спрятан*, а не *как обучить*.
2. **Сюжет → гипотезы.** Каждую «странную» фразу записываем как техническую гипотезу. В 2025 году каждая такая фраза оказывалась подсказкой.
3. **Дешёвые проверки первыми (≤ 15 мин):** метаданные и имена файлов, кодировки, LSB, сортировка/сглаживание, ответы модели «как есть».
4. **Оценка:** `ожидаемые очки / ожидаемые часы`. Берём задачи с лучшим отношением и есть ли частичные очки **[зависит от регламента]**.
5. **Обучение — только после доказательства**, что ответ от него зависит.

**Stop conditions (обязательны):**

- 20 минут без новой подтверждённой гипотезы → записать состояние в таблицу, сменить задачу или человека.
- Обучение идёт > 20 минут, а явной связи «метрика → флаг» нет → остановить.
- Задача требует скачать > 2 ГБ или запустить чужой код → сначала пересчитать ценность, сначала читать код, по возможности работать в изоляции.
- Подсказка за очки **[зависит от регламента]**: брать, если задача стоит на месте > 40 минут и её стоимость минус цена подсказки выше, чем у следующей задачи в очереди.
- Ответ выглядит бессмысленно, но получен корректно → **сдавать, не «исправлять»** (урок Paraguay).

## 4. Безопасное окружение

```bash
python3.11 -m venv ~/lmml && source ~/lmml/bin/activate
pip install -U pip
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu  # для CUDA — сборка с pytorch.org под свою версию
pip install numpy pandas scipy scikit-learn matplotlib jupyterlab \
            safetensors huggingface_hub "transformers>=4.45"
pip install lightgbm xgboost opencv-python-headless pillow \
            librosa soundfile gymnasium stable-baselines3 \
            adversarial-robustness-toolbox picklescan
pip freeze > lock.txt
```

Правила (выведены из рисков Australia, см. аудит §4.1):

- Веса читать через `safetensors.safe_open(..., framework="np")`: это не выполняет код.
- `trust_remote_code=True` — **только** после чтения `*.py` в репозитории модели и с `revision="<commit sha>"`.
- `.bin`/`.pt`/`.pkl`: сначала `picklescan`, потом `torch.load(path, weights_only=True)`. Никогда не делать `pickle.load` на чужих файлах.
- Чужие notebook'и и скрипты запускать в отдельном контейнере (`docker run --rm --network none -v $PWD:/w ...`) или хотя бы в отдельном пользователе/venv **без токенов** в окружении.
- Загружать веса в исходном dtype: не fp16/bf16 и без квантования, если ищете что-то в младших битах.
- Gated-модели: условия принимать заранее; токен только read-only.

## 5. Шаблоны (общие, не под конкретное задание)

### 5.1 `inspect_weights.py` — инвентаризация весов без выполнения кода

```python
import sys, numpy as np
from safetensors import safe_open

path = sys.argv[1]
with safe_open(path, framework="np") as f:
    print("metadata:", f.metadata())
    for name in f.keys():
        t = f.get_tensor(name)
        row = f"{name:60s} {str(t.dtype):8s} {str(t.shape):22s}"
        if t.dtype == np.float32:
            lsb = (t.view(np.uint32) & 1).astype(np.float64)
            # ~0.5 — норма; заметное смещение или начало, отличающееся от остального тензора — повод для проверки
            row += f" mean={t.mean():+.4g} std={t.std():.4g} lsb1={lsb.mean():.4f} lsb1_head={lsb.ravel()[:4096].mean():.4f}"
        print(row)
```

Что ещё смотреть: дубли и tied-тензоры, лишние или неиспользуемые тензоры (сравнить число параметров с архитектурой), строки в `metadata()`, в `config.json` и в токенизаторе (`added_tokens.json`).

### 5.2 `inspect_data.py` — первые 10 минут с датасетом

```python
import sys, numpy as np, pandas as pd, matplotlib.pyplot as plt
df = pd.read_csv(sys.argv[1])
print(df.shape); print(df.dtypes); print(df.head()); print(df.describe(include="all").T)
print("NaN:", df.isna().sum().to_dict()); print("dups:", df.duplicated().sum())
print("nunique:", df.nunique().to_dict())
num = df.select_dtypes("number")
for c in num:                                   # целые 32..126 → возможно ASCII
    v = num[c].dropna()
    if (v == v.round()).all() and v.between(32, 126).mean() > 0.9: print("ASCII?", c)
if num.shape[1] >= 2:                           # сигнал в шуме: сортировка + сглаживание
    x, y = num.columns[:2]; s = df.sort_values(x)
    sm = s[y].rolling(max(5, len(s)//500), center=True).median()
    plt.figure(figsize=(14, 4)); plt.scatter(s[x], s[y], s=1, alpha=.2); plt.plot(s[x], sm, "r"); plt.show()
```

Плюс: порядок строк и ID (утечки), распределение таргета, корреляции, train/test-сдвиг; для лидербордов — локальная CV, повторяющая разбиение организаторов.

### 5.3 Базовые «бейзлайны за 10 минут»

- Таблицы: `HistGradientBoosting` / LightGBM + KFold. Сначала бейзлайн, потом фичи.
- CV: предобученный ResNet/ViT как feature extractor + логистическая регрессия **[зависит от регламента про pretrained]**.
- NLP: TF-IDF + LogisticRegression, затем при необходимости маленький трансформер.
- RL: сначала посмотреть на среду (награды, пространство действий, детерминизм) и случайного агента; эвристика/табличный Q-learning раньше PPO.
- Adversarial: FGSM/PGD из ART на CPU; проверить, нужна ли вообще атака (может, ответ лежит в данных или модели).
